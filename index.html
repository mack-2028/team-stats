Handbook: how this whole system works

Written for the next person who takes this over. No coding needed for the checklists. Where a step needs the code, it says exactly which file. No passwords are written here (this page is public). The previous owner hands logins over separately.

1. The big picture

Scouts type or tap what they see into the tablet app. The data is saved on the tablet and copied to the cloud database (Firebase). The website reads the cloud database and turns it into tables, rankings, predictions and pick lists. Everything about the game itself (points, words, the manual) lives in the Game Guide tab of the same website.

2. Before every event

  1. Charge every tablet. Install the newest APK on all of them (see section 5).
  2. On the master tablet, open Setup and make a new profile for this competition. Each competition is its own profile, so old data never mixes in.
  3. Load the team list and match schedule into that profile (from The Blue Alliance, typed in, or from a photo).
  4. Check the scouting questions in the profile. For FTC they should match the buttons in Game Guide → What to tap.
  5. Do a test: scout one fake match, send it to the website, confirm it shows up, then delete it.
  6. Check that the phone hotspot works. Venues often have no WiFi, so the plan is a hotspot or moving data by QR code and the app's Data page.
  7. Open the website, pick the event, and check Teams and the schedule look right.

3. During the event

  • Scouts only use the tablets. The laptop is for the website, sorting data after day 1, downloading the APK and fixing problems.
  • Send data often (hotspot sync, QR code, or the Data page). Do it before each match if you can so the pit tablet and phone are current.
  • Use Data Validation to find missing or odd rows. A 10 to 30 percent error in scouting data is normal and fine.

4. Prescouting (before an event)

  • Prescout tab: pick an earlier event and see every team's numbers.
  • Match Watcher tab: watch a YouTube match video, tap in what you saw, save. Those rows appear in Prescout under "Video scouting". Paste the match times from the video description into "Jump to a match" so you can skip around a long stream. Add the teams you follow so it can show only their matches.
  • The Match Watcher buttons come from the GAME settings block, so they always match the Game Guide.

5. Changing something (the safe way)

  1. Website change: open team-stats-live.html on GitHub, click the pencil, change it, click Commit. The public site updates in about a minute. Press Ctrl+F5 to see it.
  2. Put the change in the app too: double-click make-site-blob.bat (in the tools folder next to this website file; needs Python installed). It reads team-stats-live.html and writes a new site_blob.py. Upload that file to scout-full/app/src/main/python/ in the scout-app repo.
  3. Get the new APK: in the scout-app repo open Actions, wait for the newest run to turn green, open it and download the APK. Install it on each tablet.
  4. Undo: every GitHub file has a History button. Open an older version and use it to restore the old text.
  5. Change one thing at a time and test before the next change.

6. When it breaks
My website change does not showDid you press Commit? Wait a minute, then Ctrl+F5. If it only fails in the tablet app, you forgot step 2 and 3 of section 5 (site_blob.py and a new APK).
Website says it could not connect to FirebaseCheck the internet. Then check the Firebase project is still on and its database rules have not expired (Firebase console → Firestore → Rules).
Tablets will not syncNo internet. Use the Data page: QR code, nearby transfer over the hotspot, or export and import.
Same match appears twiceUse Data Validation to find it and delete one. Rows have a fingerprint so a re-sent row should merge, not duplicate.
The APK build shows a red X in ActionsOpen the red run, open the failed step, copy the error text, and give it to Claude (see section 9). Usually a file went into the wrong folder.
Match Watcher video will not playIt needs internet. Some videos block embedding; open the video on YouTube and watch it there, then type the numbers in.
Match Watcher will not saveSame as the Firebase problem above. It writes to the same database as everything else.
"pip is not recognized" on the laptopType python -m pip instead of pip, and open the window from inside the right folder.

7. New season (do this every September)

  1. FTC and FRC are two different games with two different manuals, and each has its own settings block. Do this section once for FTC (kickoff is in September) and once for FRC (kickoff is in January). Switch FTC/FRC at the bottom of the screen first, then open the Game Guide tab. Under "New season", load that game's manual PDF so you can search it. Loading a PDF only changes what you can search. It does not change the point table, buttons or words (those come from step 2).
  2. Read the game and scoring sections. Open team-stats-live.html and find the blocks GAME_FTC and GAME_FRC (under the heading GAME SETTINGS). Edit the one for the game you are updating. Change the name, point values v, ranking goals rp, the fields (the buttons) and the terms (the glossary). Keep field id names if the meaning is the same, so old data still lines up.
  3. The built-in searchable manual pages are in a line starting const GAME_PAGES. They are the FTC pages only. They are old for a new season; loading the PDF replaces them on that device. FRC has no built-in pages until someone adds them. Ask Claude to refresh them if you want them built in again.
  4. Make a new profile in the app Setup and type the new scouting questions from Game Guide → What to tap.
  5. Do section 5 (website, site_blob.py, new APK), then do the test in section 2.

8. Words you will see

  • Repo (repository): a folder of files on GitHub.
  • Commit: saving a change on GitHub. It keeps the old version too.
  • Actions: GitHub's robot. It builds the APK when you upload files.
  • APK: the installable app file for Android tablets.
  • Firebase / Firestore: the cloud database. The collection named submissions holds the scouted rows.
  • Profile: one competition's worth of settings, teams, matches and data.
  • site_blob.py: the website, squeezed into text so it can live inside the app.
